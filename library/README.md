# ห้องสมุด (Library)

ที่เก็บเอกสารรายงาน/สรุปข่าวสาร แยกไว้ต่างหาก **ยังไม่เข้าเว็บ** (จะนำเข้าเว็บภายหลังเมื่อผู้ใช้สั่ง)

## กติกา (ผู้ใช้กำหนดแล้ว)
- เพิ่ม/แก้เอกสารได้เฉพาะ admin
- บุคคลที่มีชื่อในเอกสาร **ผูกกับการ์ดบุคคล** — ตอนนี้เก็บรายชื่อไว้ในช่อง `persons` ก่อน เมื่อนำเข้าเว็บให้หาการ์ดเดิมจากชื่อ (ไม่มี → สร้างการ์ดบุคคลสำคัญ) แล้วผูกด้วย `pref`
- วันที่เอกสาร: ใช้ตามที่ระบุในเอกสาร ไม่ทราบให้เว้นว่าง (ห้ามเดา) · `receivedAt` = วันที่ได้รับเอกสาร
- เอกสารที่มีข้อมูลส่วนบุคคล / ชั้นความลับ ห้ามเก็บแบบไม่เข้ารหัส (ใช้ `tools/secure/` แบบเดียวกับสคริปต์นำเข้า)

## รูปแบบไฟล์ (1 เอกสาร = 1 ไฟล์ JSON ในโฟลเดอร์นี้)
| ช่อง | ความหมาย |
|---|---|
| `id` | รหัสเอกสาร `lib-<ปี พ.ศ.>-<ลำดับ>` |
| `title` | เรื่อง |
| `unit` | หน่วยที่รายงาน |
| `docDate` | วันที่เอกสาร (YYYY-MM-DD ค.ศ.) ไม่ทราบ = `""` |
| `receivedAt` | วันที่ได้รับเอกสาร |
| `cats` | หมวดข่าว (ชุดเดียวกับรายงานข่าวในเว็บ) |
| `pv` | จังหวัด/พื้นที่ (ไม่บังคับ) |
| `tags` | คำค้น |
| `content` | เนื้อหาเต็ม (คงรูปแบบข้อ/บรรทัด) |
| `persons` | บุคคลที่มีชื่อในเอกสาร — สำหรับผูกการ์ดบุคคลเมื่อนำเข้าเว็บ |
| `files` | ไฟล์แนบ PDF/รูป (ถ้ามี) |
